# EndToEnd browser consumers 0.2.0

This is exact corresponding source for the retained AGPL-3.0-only full frontend, plus independently authored MIT desk source and the MIT SDK 0.2.1 it consumes. It contains editable application and SDK source, configuration, embedded guides/media, interfaces, tests, license notices and the actual build/run scripts. The separately running AGPL messaging service/agent is a separate source component; its offer must remain visible through the trusted agent and host integration.

Use Node 22.13.0 and Yarn 1.22.22. From this directory run `yarn install --frozen-lockfile --production=false --ignore-scripts --non-interactive`, then `node scripts/rebuild-sdk-consumers.mjs`. This rebuilds the MIT SDK from its included source, checks full-frontend types and tests, checks the desk JavaScript, compiles the full frontend, and installs notices. No original checkout or prebuilt frontend is used. Runtime static roots are `apps/web/dist` and `apps/desk-client`; the desk's import map loads only the included compiled MIT SDK. `scripts/serve-sdk-consumer.mjs` is the independent static host API. Supply a matching source-disclosure descriptor and its exact files when using release mode; configure the host with a distinct trusted-agent origin before navigation. The messaging service supplies its own accounts or host grants.

No source download requires login, payment, NDA or terms that reduce covered license rights. The release source archive is served alongside each exact downloadable browser component. Verify SHA-256 against the release disclosure and verify all files with CONSUMER_SOURCE_MANIFEST.json.

Preferred third-party forms: `dependencies/PREFERRED_SOURCE.json` maps exact npm archives and upstream editable React/Vite source to the bundled React/DOM/Scheduler code and generated Vite preload helper. Their notices are retained under dependencies/licenses and in the compiled frontend. General-purpose Node, Yarn, TypeScript, tsx, Vite/Rollup/esbuild/Babel tooling and Playwright browser installations are not installed tools inside this artifact; obtain those versions using the included exact lockfile. Node/Yarn and OS/system libraries are standard external tools. The Vite source is nevertheless included because its browser preload helper is emitted. This candidate has no vendor-locked User Product, firmware, signing keys or owner authorization needed to install a modified program. It has no schema, database, secret, vault or native encryption implementation; those belong to the separate messaging component.

The original SDK archive identity and original SDK manifest/provenance are retained under provenance/sdk for attribution and chain of custody; that earlier manifest describes the original MIT SDK artifact, not this combined consumer workspace. SDK package licenses retain MIT. MODIFICATIONS.md records first-party changes. No production deployment or publication is performed by these scripts.
